# Lyria 3.5

> Source: https://ai.google.dev/gemini-api/docs/models/lyria-3.5

Lyria 3.5 is Google's flagship music generation model. It is optimized for generating full-length songs with complex structural coherence, including multiple verses, choruses, and bridges. It generates high-quality, 44.1 kHz stereo audio from text prompts or image inputs.

[Try in Google AI Studio](https://aistudio.google.com/prompts/new_chat?model=lyria-3.5)
