# Gemini Triggers API

Note: This API is in Beta. Endpoints are under `/v1beta/`.

Triggers allow you to schedule agent executions on a cron schedule, enabling automated and recurring tasks.

## Triggers

### CreateTrigger

`POST https://generativelanguage.googleapis.com/v1beta/triggers`

Creates a new trigger that will invoke the specified agent on the given
cron schedule.
