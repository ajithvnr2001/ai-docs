# triggers

> Source: https://ai.google.dev/api/triggers.md.txt

Triggers allow you to schedule agent executions on a cron schedule, enabling automated and recurring tasks.
[View as markdown](https://ai.google.dev/static/api/triggers.md.txt) [View the OpenAPI Spec](https://ai.google.dev/static/api/interactions.openapi.json)

> [!NOTE]
> This API is in Beta. Endpoints are under `/v1beta/`.

## CreateTrigger

post https://generativelanguage.googleapis.com/v1beta/triggers Creates a new trigger that will invoke the specified agent on the given
cron schedule.
- [Request body](https://ai.google.dev/api/triggers#CreateTrigger.request_body)
- [Response](https://ai.google.dev/api/triggers#CreateTrigger.response)

### Request body

The request body contains data with the following structure:
