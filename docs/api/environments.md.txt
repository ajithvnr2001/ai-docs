# Gemini Environments API

Note: This API is in Beta. Endpoints are under `/v1beta/`.

Environments provide isolated execution contexts for running agent code, tools, and services securely.

## Environments

### CreateEnvironment

`POST https://generativelanguage.googleapis.com/v1beta/environments`

Creates an environment.


#### Request Body
- **network** (`EnvironmentNetworkEgressAllowlist or enum (string)`) Network configuration for the environment.
  Possible values:
  - `disabled`: All network egress is blocked.
  - **allowlist** (`array (EgressRule) or enum (string)`)   List of allowed domains and their configurations. Set to `"disabled"` to block all network egress.
    Possible values:
    - `disabled`: All network egress is blocked.


- **sources** (`array (Source)`) Sources to be mounted into the environment.
  - **type** (`enum (string)`)
    Possible values:
    - `gcs`: A Cloud Storage bucket.
    - `inline`: Inline content.
    - `repository`: A generic repository. The protocol prefix in the source URL
identifies the provider (e.g., github://, gcs://).

  - **source** (`string`)   The source of the environment. For Cloud Storage, this is the Cloud Storage path. For GitHub, this is the GitHub path.

  - **target** (`string`)   Where the source should appear in the environment.

  - **content** (`string`)   The inline content if `type` is `INLINE`.

  - **encoding** (`string`)   Optional encoding for inline content (e.g. `base64`).


- **from_environment** (`string`) Optional. The source environment to copy/fork from. Format: `environments/{environment_id}` or `{environment_id}`. When specified, `sources` and `env` must be empty.


#### Response
- **id** (`string`) *(Required)* Required. Output only. The ID of the environment.

- **network** (`EnvironmentNetworkEgressAllowlist or enum (string)`) Network configuration for the environment.
  Possible values:
  - `disabled`: All network egress is blocked.
  - **allowlist** (`array (EgressRule) or enum (string)`)   List of allowed domains and their configurations. Set to `"disabled"` to block all network egress.
    Possible values:
    - `disabled`: All network egress is blocked.


- **sources** (`array (Source)`) Sources to be mounted into the environment.
  - **type** (`enum (string)`)
    Possible values:
    - `gcs`: A Cloud Storage bucket.
    - `inline`: Inline content.
    - `repository`: A generic repository. The protocol prefix in the source URL
identifies the provider (e.g., github://, gcs://).

  - **source** (`string`)   The source of the environment. For Cloud Storage, this is the Cloud Storage path. For GitHub, this is the GitHub path.

  - **target** (`string`)   Where the source should appear in the environment.

  - **content** (`string`)   The inline content if `type` is `INLINE`.

  - **encoding** (`string`)   Optional encoding for inline content (e.g. `base64`).


- **created** (`string`) Output only. The time at which the environment was created in ISO 8601 format (YYYY-MM-DDThh:mm:ssZ).

- **updated** (`string`) Output only. The time at which the environment was last updated in ISO 8601 format (YYYY-MM-DDThh:mm:ssZ).

- **last_accessed** (`string`) Output only. The time at which the environment was last accessed in ISO 8601 format (YYYY-MM-DDThh:mm:ssZ).

- **status** (`enum (string)`) Output only. The status of the environment container.
  Possible values:
  - `active`: Output only. The status of the environment container.
  - `expired`: Output only. The status of the environment container.

- **file_count** (`string`) Output only. The number of files in the environment, output only.

- **size_bytes** (`string`) Output only. The total size of the environment files in bytes, output only.

### GetEnvironmentFiles

`GET https://generativelanguage.googleapis.com/v1beta/environments/{environment}/files/{path}`

Retrieves file metadata or directory contents from an environment's snapshot. To download file content, use the download URL returned in the response.

#### Parameters
- **page_size** (`integer`) Optional. Maximum number of entries to return per page (for directory listing).

- **page_token** (`string`) Optional. Pagination token for directory listing.

- **recursive** (`boolean`) Optional. If true and the path is a directory, recursively lists all files.



#### Response
- **files** (`array (EnvironmentFile)`) If the requested path is a directory, this contains its contents. If the requested path is a file, this contains a single entry with the file's metadata. If alt=media was specified, this is empty (content is served via `blob`).
  - **name** (`string`)   Output only. The name of the file or directory (e.g., "main.py" or "src").

  - **path** (`string`)   Output only. The full relative path within the environment (e.g., "workspace/src/main.py").

  - **type** (`enum (string)`)   Output only. The type of the entry.
    Possible values:
    - `file`: A regular file.
    - `directory`: A directory.

  - **size_bytes** (`string`)   Output only. The size of the file/directory in bytes. NOLINT

  - **mime_type** (`string`)   Output only. The MIME type of the file (e.g., "text/python", "image/png"). Empty for directories. NOLINT

  - **created** (`string`)   Output only. The creation time of the file/directory.

  - **modified** (`string`)   Output only. The modification time of the file/directory.


- **next_page_token** (`string`) Pagination token for directory listing. NOLINT

### Start an environment file upload

`PUT https://generativelanguage.googleapis.com/upload/v1beta/environments/{environment}/files/{path}`

Starts a resumable upload session for a file in an environment workspace.
Upload the file bytes to the URL returned in the `X-Goog-Upload-URL`
response header, using the resumable upload protocol.


#### Parameters
- **X-Goog-Upload-Command** (`string`) *(Required)* Command that starts the resumable upload session.
  Default: `start`
- **X-Goog-Upload-Header-Content-Length** (`integer`) *(Required)* Total number of file bytes that will be uploaded to the session URL.

- **X-Goog-Upload-Header-Content-Type** (`string`) *(Required)* MIME type of the file that will be uploaded to the session URL.

- **X-Goog-Upload-Protocol** (`string`) *(Required)* Resumable upload protocol selector.
  Default: `resumable`
- **extract** (`boolean`) Optional. If true, treats the uploaded file as a tar/tar.gz archive and unpacks it into `path`.

- **overwrite** (`boolean`) Optional. Whether to overwrite the destination file if it already exists.



#### Response
Empty response.

#### Examples
**Start Upload**

**REST**

```sh
curl -i -X PUT \
  'https://generativelanguage.googleapis.com/upload/v1beta/environments/env_abc123/files/main.py?overwrite=true' \
  -H "x-goog-api-key: $GEMINI_API_KEY" \
  -H 'X-Goog-Upload-Protocol: resumable' \
  -H 'X-Goog-Upload-Command: start' \
  -H "X-Goog-Upload-Header-Content-Length: $(wc -c < main.py)" \
  -H 'X-Goog-Upload-Header-Content-Type: text/x-python'
```

### Environment { #Resource:Environment }
An execution environment for an agent.

**Properties:**
- **id** (`string`) *(Required)* Required. Output only. The ID of the environment.

- **network** (`EnvironmentNetworkEgressAllowlist or enum (string)`) Network configuration for the environment.
  Possible values:
  - `disabled`: All network egress is blocked.
  - **allowlist** (`array (EgressRule) or enum (string)`)   List of allowed domains and their configurations. Set to `"disabled"` to block all network egress.
    Possible values:
    - `disabled`: All network egress is blocked.


- **sources** (`array (Source)`) Sources to be mounted into the environment.
  - **type** (`enum (string)`)
    Possible values:
    - `gcs`: A Cloud Storage bucket.
    - `inline`: Inline content.
    - `repository`: A generic repository. The protocol prefix in the source URL

  - **source** (`string`)   The source of the environment. For Cloud Storage, this is the Cloud Storage path. For GitHub, this is the GitHub path.

  - **target** (`string`)   Where the source should appear in the environment.

  - **content** (`string`)   The inline content if `type` is `INLINE`.

  - **encoding** (`string`)   Optional encoding for inline content (e.g. `base64`).
