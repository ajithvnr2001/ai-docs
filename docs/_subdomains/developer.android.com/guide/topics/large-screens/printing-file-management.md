Desktop and productivity users rely on file managers and expect multipurpose access to content, including output in portable and printed formats.

## Printing

Support document printing or document export to a printable format such as PDF.

## File management

Add a key desktop capability to your app by implementing common file management functionality.

### File picker

Integrate your app with the OS file picker, ensuring seamless import and export of content.

### File handlers

Enable your app to designate itself as a file handler by declaring support for relevant file types so users can open files directly from the system's **Files** app.
