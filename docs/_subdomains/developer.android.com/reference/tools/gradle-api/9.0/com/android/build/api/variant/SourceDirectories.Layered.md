# SourceDirectories.Layered

[View Source](https://cs.android.com/search?q=file:com/android/build/api/variant/SourceDirectories.kt+class:com.android.build.api.variant.SourceDirectories.Layered)

Added in 7.3.0
    
    
    interface [SourceDirectories.Layered](https://developer.android.com/reference/tools/gradle-api/9.0/com/android/build/api/variant/SourceDirectories.Layered) : [SourceDirectories](https://developer.android.com/reference/tools/gradle-api/9.0/com/android/build/api/variant/SourceDirectories)

* * *

Represent a collection of directories that have overlay properties to each other. This mean that some directories will carry higher priority when merging content will be carried out.

The collection is represented as a `[List](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.collections/-list/index.html)` where the first elements are the highest priority ones.

For a specific priority, there can be more than one directory defined and is represented as a `[Collection](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.collections/-collection/index.html)` of `[Directory](https://docs.gradle.org/current/javadoc/org/gradle/api/file/Directory.html)`.

Therefore, `[Layered](https://developer.android.com/reference/tools/gradle-api/9.0/com/android/build/api/variant/SourceDirectories.Layered)` can be represented as a `[List](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.collections/-list/index.html)` of `[Collection](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.collections/-collection/index.html)` of `[Directory](https://docs.gradle.org/current/javadoc/org/gradle/api/file/Directory.html)`.

## Public properties

### all
    
    
    val [all](https://developer.android.com/reference/tools/gradle-api/9.0/com/android/build/api/variant/SourceDirectories.Layered#all\(\)): [Provider](https://docs.gradle.org/current/javadoc/org/gradle/api/provider/Provider.html)<[List](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.collections/-list/index.html)<[Collection](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.collections/-collection/index.html)<[Directory](https://docs.gradle.org/current/javadoc/org/gradle/api/file/Directory.html)>>>

Get all registered source folders and files as a `[List](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.collections/-list/index.html)` of `[Collection](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.collections/-collection/index.html)` of `[Directory](https://docs.gradle.org/current/javadoc/org/gradle/api/file/Directory.html)`.

The outer `[List](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.collections/-list/index.html)` represents the priority of `[Directory](https://docs.gradle.org/current/javadoc/org/gradle/api/file/Directory.html)` respective to each other, meaning that elements first in the list overrides elements last in the list.

The inner `[Collection](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.collections/-collection/index.html)` represents all `[Directory](https://docs.gradle.org/current/javadoc/org/gradle/api/file/Directory.html)` with the same priority respective to each other.

The returned `[Provider](https://docs.gradle.org/current/javadoc/org/gradle/api/provider/Provider.html)` can be used directly in a `[org.gradle.api.tasks.InputFiles](https://docs.gradle.org/current/javadoc/org/gradle/api/tasks/InputFiles.html)` annotated property of a `[Task](https://docs.gradle.org/current/javadoc/org/gradle/api/Task.html)`
