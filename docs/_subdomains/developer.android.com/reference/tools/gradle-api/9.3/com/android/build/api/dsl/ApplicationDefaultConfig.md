# ApplicationDefaultConfig

[View Source](https://cs.android.com/search?q=file:com/android/build/api/dsl/ApplicationDefaultConfig.kt+class:com.android.build.api.dsl.ApplicationDefaultConfig)

Added in 4.2.0
    
    
    interface [ApplicationDefaultConfig](https://developer.android.com/reference/tools/gradle-api/9.3/com/android/build/api/dsl/ApplicationDefaultConfig) : [ApplicationBaseFlavor](https://developer.android.com/reference/tools/gradle-api/9.3/com/android/build/api/dsl/ApplicationBaseFlavor), [DefaultConfig](https://developer.android.com/reference/tools/gradle-api/9.3/com/android/build/api/dsl/DefaultConfig)

* * *

Specifies defaults for properties that the Android application plugin applies to all build variants.

You can override any `defaultConfig` property when [configuring product flavors](https://developer.android.com/studio/build/build-variants.html#product-flavors). See `[ApplicationProductFlavor](https://developer.android.com/reference/tools/gradle-api/9.3/com/android/build/api/dsl/ApplicationProductFlavor)`.
