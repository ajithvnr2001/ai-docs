Represents a built artifact that is present in the file system.

This is part of the `[BuiltArtifactsLoader](https://developer.android.com/reference/tools/gradle-api/9.3/com/android/build/api/variant/BuiltArtifactsLoader)` API to read the content of the APK folder generated by the build.
