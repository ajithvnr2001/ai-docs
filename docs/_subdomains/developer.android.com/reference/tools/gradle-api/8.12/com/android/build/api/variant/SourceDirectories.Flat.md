# SourceDirectories.Flat

[View Source](https://cs.android.com/search?q=file:com/android/build/api/variant/SourceDirectories.kt+class:com.android.build.api.variant.SourceDirectories.Flat)

Added in 7.3.0
    
    
    interface [SourceDirectories.Flat](https://developer.android.com/reference/tools/gradle-api/8.12/com/android/build/api/variant/SourceDirectories.Flat) : [SourceDirectories](https://developer.android.com/reference/tools/gradle-api/8.12/com/android/build/api/variant/SourceDirectories)

* * *

Represents all the source folders for a source type in the variant.

All folders are considered of the same priority, so if there is a conflict (e.g, two files with the same relative path and name), it will require a resolution step like merging to ensure nothing gets lost.

Get all registered source folders and files as a `[List](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.collections/-list/index.html)` of `[Directory](https://docs.gradle.org/current/javadoc/org/gradle/api/file/Directory.html)`.

Some source types do not have the concept of overriding, while others require a merging step to ensure only one source file is used when processing begins.

The returned `[Provider](https://docs.gradle.org/current/javadoc/org/gradle/api/provider/Provider.html)` can be used directly in a `[org.gradle.api.tasks.InputFiles](https://docs.gradle.org/current/javadoc/org/gradle/api/tasks/InputFiles.html)` annotated property of a `[Task](https://docs.gradle.org/current/javadoc/org/gradle/api/Task.html)`
