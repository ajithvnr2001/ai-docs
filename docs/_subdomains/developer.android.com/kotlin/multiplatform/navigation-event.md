Navigation Event is a library that provides a Kotlin Multiplatform (KMP) solution for integrating system-level navigation events into your application. It is designed to be the foundational layer for handling navigation directions across various supported platforms.

See the [Navigation Event](https://developer.android.com/guide/navigation/navigation-event) documentation for more information.
