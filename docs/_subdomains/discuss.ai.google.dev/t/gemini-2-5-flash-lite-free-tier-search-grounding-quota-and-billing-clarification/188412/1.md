Hi Everyone,
Starting June 19, 2026, the Gemini API will stop accepting requests from unrestricted API keys to prevent unauthorized usage and billing risks.
If your Google Cloud project has the Gemini API enabled and contains unrestricted keys, please restrict them immediately.
###  [](https://discuss.ai.google.dev/t/gemini-2-5-flash-lite-free-tier-search-grounding-quota-and-billing-clarification/188412#p-311902-what-to-do-1)What to do:
  * Option 1 (Restrict existing keys): Go to [Google Cloud Credentials](https://console.cloud.google.com/apis/credentials), select your key, and under API restrictions, restrict it to Gemini API ([generativelanguage.googleapis.com](http://generativelanguage.googleapis.com)).
  * Option 2 (New keys): Generate new restricted keys in [Google AI Studio](https://aistudio.google.com/app/apikey) and update your code.


Note: Keys generated directly in AI Studio are restricted to the Gemini API by default.

Hello Google AI Developer Community,
We are integrating Gemini 2.5 Flash-Lite with Google Search grounding into CVernia, a career management platform.
Our Google AI Studio project is on the Free tier, with no billing account attached.
Google AI Studio displays general model limits of 10 RPM and 20 RPD, along with a separate Search grounding chart for Gemini 2.5. However, the grounding chart does not show usable consumption data, and Google Cloud Monitoring reports “No rows to display” for the Search-grounding quota usage metric.
Could someone from the Gemini API team clarify:
  1. Is Google Search grounding available for Gemini 2.5 Flash-Lite on the Free tier without an attached billing account?
  2. What is the applicable daily Search-grounding allowance?
  3. How can developers verify their remaining project-wide grounding allowance?
  4. Does the Search-grounding limit displayed in AI Studio represent a free allowance or a technical quota?
  5. If the allowance is exhausted, are requests rejected without charges, or could any billable usage occur?


We have disabled live grounding requests until we can establish the applicable quota and billing behaviour.
Thank you for your guidance.
CVernia
