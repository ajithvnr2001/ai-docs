Hi Everyone,
Starting June 19, 2026, the Gemini API will stop accepting requests from unrestricted API keys to prevent unauthorized usage and billing risks.
If your Google Cloud project has the Gemini API enabled and contains unrestricted keys, please restrict them immediately.
###  [](https://discuss.ai.google.dev/t/cannot-setup-cloud-billing-account-or-bacr2-59/188817#p-311902-what-to-do-1)What to do:
  * Option 1 (Restrict existing keys): Go to [Google Cloud Credentials](https://console.cloud.google.com/apis/credentials), select your key, and under API restrictions, restrict it to Gemini API ([generativelanguage.googleapis.com](http://generativelanguage.googleapis.com)).
  * Option 2 (New keys): Generate new restricted keys in [Google AI Studio](https://aistudio.google.com/app/apikey) and update your code.


Note: Keys generated directly in AI Studio are restricted to the Gemini API by default.

Hello [@Nelle_Deekay](https://discuss.ai.google.dev/u/nelle_deekay) ,
Please try the below steps from [Troubleshoot Google Cloud signup issues](https://docs.cloud.google.com/support/docs/troubleshoot-signup):
  * Pay any outstanding balance on your existing Google Cloud or other Google accounts. If AI Studio shows “Another payment profile has an issue”, click “Visit Cloud Console to diagnose” and make the payment the Cloud Console asks for.
  * Enter your name and billing address exactly as your bank or card issuer has them, and use a standard credit or debit card that allows international and recurring payments.
  * Turn off any VPN or proxy, then retry the billing setup in an Incognito window.
  * If it still fails, contact Cloud Customer Care through the [Account suspension inquiry form](https://support.google.com/cloud/contact/cloud_platform_suspensions).
