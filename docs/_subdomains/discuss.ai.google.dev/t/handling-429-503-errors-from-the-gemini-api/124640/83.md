Hello Gemini API Team,
I am experiencing repeated HTTP 429 errors when using the Gemini API, even though Google AI Studio shows that my project is well below its rate limits.
**Environment**
  * Project ID: `gen-lang-client-00499242...`
  * Usage tier: Free
  * Model: `gemini-3.6-flash`
  * API: `POST /v1beta/interactions`
  * Execution environment: GitHub Actions


**Failures on October 14, 2026**
  * 00:08:33 UTC: HTTP 429
  * 03:41:26 UTC: HTTP 429


Both requests failed immediately with:
`{"error":{"message":"Your project has exceeded a quota. See https://ai.dev/rate-limit to manage your rate limits.","code":"too_many_requests"}}`
**Google AI Studio displayed usage**
  * RPM: 1 / 5
  * TPM: 3.39K / 250K
  * RPD: 2 / 20


The usage dashboard also shows two HTTP 429 errors corresponding to these failures.
The same workflow successfully generated content with Gemini 3.6 Flash on October 11, 2026.
Could you please investigate why these requests were rejected despite the displayed quota usage being below the limits?
In particular, I would like to know whether an additional quota, temporary capacity restriction, or project-specific limitation is responsible.
Thank you for your assistance.
